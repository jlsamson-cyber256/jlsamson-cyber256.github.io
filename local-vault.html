Local Vault

Encrypted password vault. Runs inside this one file, with no network access.

Use at least 12 characters. A long passphrase works well. There is no recovery: if the master password is lost, the vault cannot be opened.

How it works and its limits
  • Key derivation: PBKDF2-SHA-256 (Password-Based Key Derivation Function 2 using the Secure Hash Algorithm, 256-bit) with 600,000 iterations and a random 16-byte salt. The count follows OWASP (Open Worldwide Application Security Project) guidance.
  • Encryption: AES-256-GCM (Advanced Encryption Standard, 256-bit key, Galois/Counter Mode). A fresh random 12-byte initialization vector is generated on every save, and the settings are bound to the ciphertext as authenticated data.
  • Storage: only ciphertext is written to this browser’s localStorage. Clearing site data deletes the vault, so use Export backup regularly and keep the backup file somewhere safe.
  • Network: a Content Security Policy (CSP) in this file blocks all outbound requests, so the page cannot send data anywhere.
  • Auto-lock: after 5 minutes without input, or 60 seconds after the tab is hidden. Copied secrets are cleared from the clipboard after 20 seconds.
  • Limits: no sync, no browser autofill, and no independent security audit. Malware, a keylogger, or a malicious browser extension on this device can defeat any browser-based vault. Strength readouts are upper-bound estimates and do not detect dictionary words or patterns.
